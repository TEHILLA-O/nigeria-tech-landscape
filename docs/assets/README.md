# Assets policy

Do **not** mass-download trademarked company logos into this repo.

Preferred approach:

- Keep `Website` and optional `Logo_URL` columns pointing at the company site or an official brand kit URL.
- Use text / SVG diagrams owned by this project for methodology or sector maps.
- If a logo pack is required later, obtain written permission or use only assets explicitly released under a permissive licence, and store provenance beside the file.

Hotlinking scraped Google Image results is not allowed.
